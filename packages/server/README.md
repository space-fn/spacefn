# @spacefn/server

Web API server runtime and file-based Vite integration for SpaceFn applications.

```ts
import { createServer } from "@spacefn/server";
import middlewares from "#space/middlewares";
import pages from "#space/pages";
import routes from "#space/routes";

export default createServer({ routes, pages, middlewares });
```

`createServer` returns `(request: Request) => Promise<Response>`. Routes, pages, and middleware are generated by `@spacefn/server/vite`; the generated modules expose named and default exports.

```bash
spacefn dev
spacefn build
```
