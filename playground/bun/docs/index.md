# About this app

Notes on how this app works, for whoever works on it next. `npm run docs` shows this folder next to spacefn's docs, and `npm run dev` serves the same at `/__space/docs/`.

Every Markdown file here is a page and every folder a group in the sidebar. spacefn's [Writing docs](spacefn/writing-docs.md) page shows what a page can have: code tabs, callouts, diagrams and HTML.
