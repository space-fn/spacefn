# spacefn app

A [spacefn](https://github.com/space-fn/spacefn) app: folders of convention files on [Effect](https://effect.website), served on Cloudflare Workers or Bun.

## Commands

| Command            | What it does                                                              |
| ------------------ | ------------------------------------------------------------------------- |
| `npm run dev`      | Runs the app locally, reloading on every change                           |
| `npm test`         | Runs the tests in `app/`                                                  |
| `npm run build`    | Builds for production (Bun: `.space/dist`)                                |
| `npm run deploy`   | Deploys (Cloudflare: your account; Bun: a Docker container), stage `prod` |
| `npx space doctor` | Checks what dev and deploy need                                           |

Local settings go in `.env` (copy `.env.example`). A deploy reads `.env.<stage>`, e.g. `.env.prod`, or the environment.

## Where things go

```txt
app/pages/          pages: index.ts is /, todos/[id].ts is /todos/:id
app/routes/         JSON and other HTTP endpoints
app/middleware/     runs before every request, in file-name order
app/db/main/        migrations/ and queries/ in SQL; import @space/db/main.ts
app/queues/         queue consumers, one per file
app/crons/          scheduled jobs, one per file
app/client/         browser scripts and stylesheets, bundled by Vite
app/env.ts          the variables the app reads
configs/            space.ts (target, aliases), plus optional vite.config.ts and infra.ts
.space/             generated by `space gen`; never edit it
```

Files whose name starts with `_` (like `app/pages/_layout.ts`) are private helpers: no page or route is made from them.
