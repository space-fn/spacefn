# spacefn app

A [spacefn](https://github.com/space-fn/spacefn) app: folders of convention files on [Effect](https://effect.website), served on Cloudflare Workers or Bun.

## Commands

| Command            | What it does                                                              |
| ------------------ | ------------------------------------------------------------------------- |
| `npm run dev`      | Runs the app locally, reloading on every change                           |
| `npm test`         | Runs the tests                                                            |
| `npm run build`    | Builds for production (Bun: `dist/`)                                      |
| `npm run deploy`   | Deploys (Cloudflare: your account; Bun: a Docker container), stage `prod` |
| `npm run docs`     | Shows `docs/` and spacefn's docs in the browser                           |
| `npx space doctor` | Checks what dev and deploy need                                           |

Local settings go in `.env` (copy `.env.example`). A deploy reads `.env.<stage>`, e.g. `.env.prod`, or the environment.

## Where things go

`app/` holds what spacefn reads, and each file there only connects code from `modules/` and `lib/`.

```txt
app/entry.ts        the app: its services, what wraps every request, onError
app/routes/         pages and endpoints: index.ts is /, todos/[id].ts is /todos/:id;
                    _middleware.ts wraps the requests to its folder
app/db/main/        config.json (driver, migrateOn), migrations/ and queries/ in SQL;
                    import #space/db/main.ts
app/queues/         queue consumers, one per file
app/crons/          scheduled jobs, one per file
app/client/         browser entries, bundled by Vite; a page loads them with assets("name")
modules/<feature>/  a feature's logic, views, client code and tests, e.g. modules/todos/
lib/                code features share: lib/ui/ has the layout and the base styles
public/             files served as they are at /
docs/               notes on this app, in Markdown: npm run docs shows them
configs/            env.ts (the variables the app reads), vite.ts (Vite, with spacefn's
                    plugin and the target), vitest.ts, tsconfig.json
.space/             generated by `space gen`; never edit it
```

Import from the app root with `#modules/...`, `#lib/...` and `#configs/...`. `npm test` runs every `*.test.ts` in `app/`, `modules/` and `lib/`.
