# Space Framework

Meta framework for Cloudflare Workers. Convention-based routing with h3. Server-rendered HTML with DataStar.

## Platform

Targets Cloudflare Workers only. No other cloud provider support.

## Project Structure

```
.space/             Vite-generated code (gitignored)
configs/
  oxlint.ts         Linter config
  oxfmt.ts          Formatter config
src/
  routes/           Server routes (file-based)
  middlewares/       Request preprocessing (ordered)
  main.ts           Entry point
wrangler.toml       Cloudflare config
```

## Entry Point

User defines `src/main.ts`. No magic entry file. Convention-based code generation in `.space/`.

```ts
// src/main.ts
import { createServer } from "@spacefn/server";

// Generated by vite plugin from src/routes/ and src/middlewares/
import routes from "#space/routes";
import middlewares from "#space/middlewares";

export default createServer({
	routes,
	middlewares,
});
```

`#space/*` aliases resolve to `.space/` folder. Generated files are created by the Vite plugin during build and dev.

## Routing

File-based conventions. File names map to URL patterns.

```
src/routes/index.ts          →  / (all methods)
src/routes/index.get.ts      →  / (GET)
src/routes/index.post.ts     →  / (POST)
src/routes/books/index.ts    →  /books (all methods)
src/routes/books/[slug]/index.get.ts  →  /books/:slug (GET)
src/routes/categories/[id].ts →  /categories/:id (all methods)
```

## Middlewares

Ordered preprocessing. Filename prefix determines order.

```
src/middlewares/1.logger.ts   →  Runs first
src/middlewares/2.cors.ts     →  Runs second
src/middlewares/3.auth.ts     →  Runs third
```

## Stack

| Layer      | Package                | Purpose                                     |
| ---------- | ---------------------- | ------------------------------------------- |
| HTML       | `@spacefn/html`        | Server-side HTML generation                 |
| CSS        | `@spacefn/css`         | Design tokens, variants, CSS output         |
| Reactivity | `@spacefn/datastar`    | Client attributes + server SSE              |
| Codegen    | `@spacefn/vite-plugin` | File watching, generation, Vite integration |
| Server     | `@spacefn/server`      | Routing, middleware, h3, Cloudflare Workers |
| Build      | Vite + tsup            | Dev server, bundling, type generation       |

## Dev Experience

```bash
pnpm dev     # Vite dev server with HMR
pnpm build   # Production build for Cloudflare
```

Route and middleware files are scanned automatically. Changes trigger regeneration and hot reload.

## Build Output

```
dist/
  _worker.js    Cloudflare Worker bundle
  public/       Static assets
```

## Design Principles

1. **Server-first**: All HTML rendered on the server. No client-side framework.
2. **Convention over configuration**: File naming drives routing. No manual route registration.
3. **Composable**: Each package is independent. Use `@spacefn/html` without `@spacefn/server`.
4. **Type-safe**: Attributes, signals, and routes are typed at compile time.
5. **Minimal**: No magic. Generated code is readable. User controls the entry point.
